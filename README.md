# Stick War Arena — Iron Front

نسخة موسعة جاهزة لـ GitHub Pages، بدون Node.js أو خادم.

## الجديد
- 15 موجة + زعيم Iron Colossus.
- 8 وحدات: عامل، سياف، رامي، رمّاح، عملاق، دبابة، مدفع، قاذف صواريخ.
- أعداء يتطورون إلى رماة ودبابات وقاذفات صواريخ.
- ضربة صاروخية خاصة قابلة للاستخدام مقابل الذهب.
- دبابات ومدافع وقذائف ذات ضرر جماعي.
- اقتصاد وترقية قاعدة وأحجار كريمة.
- مؤثرات انفجار ومقذوفات وأشرطة صحة.
- حفظ إحصاءات أساسية في LocalStorage.
- يعمل مباشرة على GitHub Pages من أربعة ملفات فقط.

## GitHub Pages
ارفع `index.html` و`style.css` و`game.js` و`README.md` إلى المستودع، ثم Settings → Pages → Deploy from branch → main → / (root).
